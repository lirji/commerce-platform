# LP11 深色经营工作台与交付收口

沿用React/Ant Design深色主题和现有能力边界，不新增UI库/图表库/中间件。

- 管理默认进入经营总览；导航按会员、商品、营销、交易、平台分组折叠，并提供全量功能快速搜索。窄屏改为抽屉导航，内容自身滚动，避免150px侧栏挤压手机页面。
- GET `/v1/admin/dashboard?storeId`：仅ADMIN且门店有效。member提供当前租户会员状态计数；catalog提供当前门店SKU状态计数；insight提供30个UTC自然日（含当日截至请求时间）的每日已投影订单/付款/实收/退款/净收/优惠承担及更新时间。按订单主键投影聚合，不从列表前50条推算，不跨旅程队列加总。
- 窗口外成功退款扣回其原订单所属日期。会员为租户级，其余为门店级，页面明确口径与异步延迟。空数据用0和说明；失败展示错误而非伪造0。金额后端精确十进制，前端数字仅用于展示图形，不参与结算。
- 各域API各自聚合权威/已有投影；app只组装响应，禁止直接跨域SQL。无承诺快照跨域强一致，不建第二写入权威。使用现有tenant/store/ordered_at索引，查询窗口有界。
- 页面按功能动态导入，登录入口不加载全部功能；保持现有表单和真实API。仪表趋势可切换净收/实收/退款；提供每日数据表便于核对，不能宣称利润或因果ROI。
- 后端验证权限、租户/门店隔离和30天窗口；浏览器验收真实指标、菜单搜索、桌面/390px布局、错误状态、渠道经营以及全部既有会员/交易流程。只在通过后正常Git主线交付，复用dev_infra更新本地Docker。
