# 会员生命周期、商品经营与深色工作台

用户已授权持续实现；2026-09-24 确认积分同时支持券/权益兑换、订单抵扣，前端偏深色数据看板。定位：可复用能力中台，兼顾品牌自营商城和会员运营。

## 本轮验收范围

1. 周期等级：周期考核、保级/降级、等级权益绑定、重复发放保护、会员可查看。
2. 积分：版本化规则、获取/到期/账本、兑换券与权益、订单抵扣冻结/核销/释放、部分退款返还及已消费奖励追回债务。
3. 会员行为与人群：生日资料、浏览/加购信号、最近成交与复购统计、动态人群、会员详情。
4. 营销闭环：定向发券任务、相对有效期、生日/沉睡/复购/加购未购买旅程、频控与等待、发放/成交/退款/成本对比；统计为描述性归因，不冒充因果增量收益。
5. 商品经营：类目、规格模板、条码与图片、检索筛选、批量操作、定时上下架/调价、按渠道定价。
6. 前端：深色统一主题、经营概览、分组导航、表单和详情改善；新功能均有实际接口页面。
7. 隔离真实 MySQL 验证、数据库演示数据、浏览器验收、文档和 CI、按任务提交并正常合并推送 main。

## 边界

沿用现有 19 模块及公共 dev_infra MySQL，不新增 Drools、MQ、缓存或独立微服务。真实支付/短信/物流、生产环境、跨项目 SDK 和完整 BI 平台不在本轮。当前本机 Docker 8602 保持可用，完成验证后才处理新版本交付。
业务金额/比例没有指定值：配置由运营发布，未配置时不自动赠送或允许抵扣；测试示例不成为正式租户政策。不承诺未经测量的吞吐/SLA。
