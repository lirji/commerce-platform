### V90 在线副本切换演练

隔离数据库验证无批次批准、活跃幂等命令、回执插入冲突回滚、成功切换、任务重复、迟到证据幂等追加及工单回读。切换只移出指定批次的两条已核实记录，待核实的第三条仍在线，版本化对象继续可读。真实 MySQL + MinIO 及 `OperationAuditMySqlTest` 共通过 5 项应用测试，日志为 `.local/operation-audit/oa09-cutover-mysql-minio.log`。正式环境开关保持关闭。

### V91 旧备份清理补放演练

在 MySQL 中独立迁移恢复 schema，将切换前的原始尝试、结果和效果重建到该 schema。源库真正切换后从版本化 MinIO 取回提交凭证。验证准备记录可作为未决批次发现、重复发布复用对象版本、篡改摘要拒绝、旧库行不同导致整批回滚、两条旧在线记录补放删除、等待核实与其他审计动作完整保留，以及第二次补放只返回已应用。该演练针对审计表及清理凭证，整库灾备恢复时长和目标部署放行仍按实际环境验收。测试日志存于 `.local/operation-audit/oa09-recovery-release.log`。

### V92 精确对象版本销毁演练

在专用 MySQL 和启用 Object Lock 的独立 MinIO 测试桶使用写入、恢复和销毁三套身份。无独立审批、仍有恢复工单及存在领域冻结时保持原版本。对象存储自带法律保全拒绝精确删除，保全取消后才处理原版本。模拟删除成功后丢失回包，首次保留准备状态，复查确认后标记过期，重试时同键另一版本仍在。独立恢复 schema 比对每条晚到证据的摘要，拒绝不一致记录并整批回滚，恢复匹配记录后才传播过期状态并清理临时副本。

隔离应用测试共 5 项，全部通过，记录位于 `.local/operation-audit/oa09-object-expiry-locked.log`。执行器默认关闭，目标环境的持有周期、存储身份、运维审批及容量仍须按 OA-10 签收。
