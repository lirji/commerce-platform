## 评审依据与差距

[Webby 官方标准](https://www.webbyawards.com/judging-criteria/)包括内容、导航、视觉、功能、交互、创新和整体体验。本轮以真实业务软件的任务完成为核心解释这些维度；不凭装饰性动效宣称创新。Awwwards 官网 evaluation 获取超时，FWA about 无可解析正文，不转述第三方权重为本轮官方事实。外部评委认可是未验证，保留品质目标，不人为下调为单一功能门槛。

基线截图实际已查看：真实经营总览、SKU 宽表、跨页接触表。差距：指标平均用力；趋势的零值/负值不准确且不可键盘探索；Ant 默认框架辨识度弱；宽表操作离开视野；中央页面仍重复壳层信息；首屏加载中央全部模块；移动图表操作没有明确触摸控件。

## 设计决定

延续品牌蓝；经营壳层采用深墨导航、浅暖画布、白色业务面。导航常驻组织/业务信息，页头减少框架装饰；关键数字用 tabular 数字、主净收深色强调，列表/详情保持高信息密度。颜色、间距、圆角由 theme.ts 与统一工作台 CSS 权威提供；不为每页建另一套 tokens。会员页面保留原配方。

总览：真正区分租户会员与门店商品/成交范围；提供有正负轴的每日金额图、当前选中日期与实际金额/订单摘要；鼠标、键盘、触摸都有路径；零值不画虚假成交柱；只展示 API 数值，不推算利润/同比。查询指标和每日数据展开状态可刷新恢复。

导航：保留可测的功能搜索，支持 Cmd/Ctrl+K 聚焦、分组结果、清晰快捷键提示；不劫持表单输入或隐藏原入口。中央跳转仍为原生地址并保留退出保护。

商品：身份/价格/状态作为扫描核心，操作列固定右侧避免隐藏；窄屏表格内部滚动；修订详情按当前对象先行，不把原始 JSON 当作默认详情。

加载：中央能力按业务页面分块，进入旧工作台不下载中央身份客户端和所有中央模块；无手工拆 vendor 只消除警告的伪优化。实际生产网络证据检查必要模块是否被下载。
