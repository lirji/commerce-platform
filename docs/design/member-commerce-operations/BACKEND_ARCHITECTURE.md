# 后端边界

保持现有模块化单体：member 拥有会员状态/成长/标签；catalog 拥有商品/规格/售价；store 拥有商家门店资源授权；campaign 拥有规则/人群/活动；journey 拥有持久旅程；效果投影通过公开领域 API 或版本化事实构建。跨模块调用仅 api 包；公共 runtime 只承载 Commands、认证、审计和消息设施。

写入统一经 Commands 幂等事务；业务状态用 expectedVersion 条件更新，影响行数不为1返回 CONFLICT。新建表含中文表/字段注释、租户主键、游标索引及金额/状态约束。禁止修改历史迁移。权限撤销即时读库，不经不确定缓存。会员冻结禁止新报价/新旅程，已付款退款和补偿可继续；注销不可恢复，资料保留供审计。

成长不等于可提现/可兑换余额。等级策略发布后按完成订单的生效策略快照计算，退款按同一策略冲回；人工调整需原因且入账。配置未启用保持原等级行为。成员事实来源限定会员域，活动不可相信客户端的等级/标签。人群快照完整发布后才供活动引用，保留版本/刷新时间和 TTL。

配置发布、促销报价、订单资金账及历史效果均绑定不可变版本。活动克隆生成新版本，预览不产生券/预算/权益效果。分析定义成交为已付款、净收入为成交实付减成功退款；营销成本单列平台/商家承担，退款回收口径与预算消耗分别显示，不能将退货自动视作营销额度恢复。
