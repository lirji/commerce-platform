# 交易中心工作台设计

本轮从 `9e5519b` 开始，复用 React、Ant Design、Hash 路由、中央授权导航和现有服务端契约。按[现行 69 个入口](../../delivery/b-console-product-experience/PAGE_CHECKLIST.md)逐页回归。旧运营 29 页、门店商品 1 页、平台工具 3 页、中央经营和协作 36 页。登录、移动菜单、组织范围、详情、表单、确认和分页纳入关联检查。

| 角色与任务 | 工作台规则 | 可观察验收 |
| --- | --- | --- |
| 运营定位订单、核对金额和流转 | 状态、应付金额和店铺靠前。店名为主、原编号保留复制。订单号打开快速核对，完整详情保留独立地址和返回位置 | 展开日期与精确查询，提交并折叠后仍能移除已应用条件。返回列表恢复原查询和焦点 |
| 商家管理商品、库存和门店 | 商品身份、规格、价格和状态优先，筛选与管理动作分层。短表单保留弹窗，较长字段独立成行 | 商品编辑校验、本次草稿、取消确认和真实提交使用原逻辑 |
| 平台核对日志和类目，中央岗位完成授权操作 | 同一壳层、列表、分页和反馈标准。组织与店铺范围随现有权限而定。中央或平台专用条件按实际使用频率分层 | 分别核对公开响应契约下的路由、字段、操作和不可用状态 |
| 管理者看经营和异常 | 保留日趋势、比较和待办下钻。工作面留给可执行数据和实际业务事实 | 已有数据口径和下钻行为回归 |

桌面布局使用紧凑左侧导航、浅灰蓝画布、白色工作面和低对比轮廓；每页保留一个可定位标题，面包屑只表示当前位置，避免在标题上方重复同一组名。侧栏和页头均复用现有组件与主题变量。1440、1920 px 利用宽屏，1024 px 检查紧凑页头，390、320 px 保留导航、搜索及独立表格横滚。图片沿用已有业务图片和占位逻辑。

搜索保留全量服务端语义。高频条件和查询、重置就近排列，精确条件和时间段可展开。折叠时仍注册字段、校验和保留已应用条件。保留现有游标与已知总量两种分页。表格维持业务列、原有批量操作和宽表设置，收敛按钮重量和行内间隔。字段错误显示于输入下方，原有权限、加载、空结果、读取失败和写入反馈保持各自语义。

先实现订单列表到完整详情、商品编辑表单并验收，随后应用到共用壳层、队列、目录、授权工作区、详情和表单。视图规格由本次需求推导，尚未经过岗位用户测试。[已有后端待补数据](../../delivery/b-console-experience-refinement/DATA_REQUIREMENTS.md)继续作为单独需求。
