# 统一电商前端架构

## 范围与事实

S10a交付同一SPA内的运营管理台和会员消费端，使用已完成S4–S9真实HTTP契约。现有平台没有前端；参考仓营销台使用React，权益台使用AntDesign，不搬入旧仓业务或改旧规则迁移门禁。外部IdP由用户明确后置，当前凭据入口只接受运维签发的不透明访问令牌；不伪造第三方登录。

## 技术与边界

React19.3.0、TypeScript7.0.2、Vite8.3.0、AntDesign6.6.5。Node24.12.0满足Vite官方20.19+/22.12+约束；Ant6官方支持React18+且不需React19兼容补丁。版本锁定package-lock.json，新增依赖检查MIT/Apache许可及npm audit。官方资料：https://vite.dev/guide/ 、https://react.dev/versions 、https://ant.design/docs/react/migration-v6/ 。不引入SSR/RSC、微前端或第二组件库。Material未选因现有B端表单经验为Ant；Tailwind未选以免另造Table/Form系统。

一个应用、两个角色壳层、一套Ant ConfigProvider主题。app负责认证/URL路由；shared包含类型化HTTP、DTO和反馈原语；features按会员购物、订单、营销、运营页面等作业组织。Hash路由避免Java端添加任意SPA回退，store选择进入hash查询参数。构建产物由Spring静态资源托管，同源API；开发Vite代理仅到本机后端。

## 信息架构

- 未登录：凭据输入、角色识别、错误恢复；令牌只存会话内存，刷新重新输入，退出清空购物车和数据。
- ADMIN：订单工作台（首页真实订单队列）、主数据（会员/商家/店铺/商品/库存）、营销（活动/人群/规则/预算）、权益（券定义/权益定义/钱包补偿）、旅程（节点编辑/版本审批/实例控制）、运营页面（组件与动作配置/真实预览/发布/回退）、履约售后（发货/收货/审批/退货/退款）、事件运维（隔离重放）。
- MEMBER：店铺商品浏览→购物袋→服务端报价→地址与确认下单→订单/支付查询与取消→售后申请；券中心/钱包、内部权益核销、站内信。
- 不存在真实渠道授权时，沙箱管理操作明确标注“本地沙箱”，不会让会员看到“真实支付成功”按钮。

## 状态、契约和一致性

服务端金额字符串直接展示；前端数量只影响报价输入，不自行宣布应付、优惠或库存结果。购物袋为会话临时态；报价在商品/券变化时失效，提交订单使用quoteId。URL只保存路线/店铺，不保存令牌和地址。GET请求可取消，切页或身份切换不能回填旧数据；操作禁用重复点击，失败重试保留相同幂等键，修改输入才新建键。状态冲突提示刷新；网络未知不当作业务失败或成功。

表单使用已知DTO，不把数据库实体或任意JSON注入业务请求。规则编辑器生成有限Compare/All/Any/Not；旅程编辑器生成已支持的WAIT/DECIDE/GRANT/NOTIFY/END；低代码只渲染已冻结数据源与动作。JSON仅在高级审阅区展示，不作为唯一产品操作界面。

列表有界游标分页；不能把当前页计数称为全平台指标。所有业务数组由API加载，无硬编码订单/商品/活动。错误保持真实401/403/409/5xx和traceId；空态与服务不可达明确不同。重要异步状态显示“已受理/处理中/结果待确认”，手动刷新或有界轮询，不伪造即时完成。

## 视觉与设备

Ant主体系，中文优先。管理台224px分组侧栏、店铺上下文条、主标题/短说明/一个主操作、队列表格和详情抽屉；消费端简洁顶栏、商品网格、44px触达按钮、移动端单列。1280px桌面为主要运营视口，375px消费端可用；管理表格在窄屏横向滚动。

主题token：canvas #EEF1F5，surface #FFFFFF，ink #111827，muted #4B5563，line #CBD5E1，accent #1D4ED8，accent-hover #1E40AF，accent-ink #FFFFFF，ok #047857，warn #B45309，err #B91C1C，pending #4338CA，idle #374151；语义填充上的文字为白色。radius6px，字号12/13/16/20px，间距4/8/16px，桌面控件32px，触屏44px，shadow 0 1px 2px rgb(17 24 39 / 12%)，focus-ring 2px solid #1D4ED8。以上映射Ant主题和共享状态Tag，CSS仅布局/焦点。

页面状态：加载显示Skeleton或Spin；空列表显示可执行下一步；403显示权限不足；401回到凭据入口；409提示刷新并保留输入；5xx/网络显示重试；提交期间禁用按钮；异步受理显示进行中；旧版本页面禁止操作。表单标签、键盘提交、抽屉焦点、文字状态和错误提示可访问。无无意义仪表盘、无假统计、无外部图片依赖。

## 后端补充契约与验收

S10a补充只读运营订单/支付视图、会员店铺目录和运行能力标识，详见s10/CONTRACTS.md。依旧所有跨域只调用API、不跨表。浏览器验收连接本地真实MySQL/HTTP，检查管理员创建/审批、会员购物/报价/下单、沙箱支付/履约/售后、低代码预览与触达。生产部署、外部渠道联调和容量承诺不在本次本地完整交付内。
