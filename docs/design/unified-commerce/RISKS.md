# 风险与后置事项

当前 S0–S10 本地实现的风险证据与分级见 [架构审查](../../../.cursor/project-analysis/architecture-risks.md)。历史设计中身份未接线、无持久化/事务等缺口已经由 S4–S10 实现，不能继续当作当前事实。

| 项目 | 当前状态/控制 | 下一边界 |
|---|---|---|
| 外部 IdP/支付/权益/WMS | 用户明确后置；本地 Bearer、持久沙箱、内部权益和本地履约 | 真实联调前补齐配置与验真/幂等/补偿合同 |
| 旧规则迁移 | 独立 BLOCKED，未修改参考仓或迁移数据 | 原迁移解除门禁后另行执行 |
| 数据完整性与并发 | 真实 MySQL、CAS/条件更新、唯一键、事务、Inbox及失败恢复测试 | 不把本地并发测试当生产容量结论 |
| 可用性/容灾 | 单实例应用与单 MySQL；无真实主切/备份恢复演练 | 生产前确定目标并隔离演练 |
| 身份和密钥 | 摘要 Bearer；租户/角色服务端校验；地址 AES-GCM；私密文件忽略 | 外部 IdP、TLS终止、密钥轮换和托管后置 |
| 数据增长/保留 | 有界批次/分页，但无自动归档；未订阅事件保留 PENDING | 确认业务保留政策，再设计分批清理/归档 |
| 业务范围 | 单店 CNY、一个活动加可叠加券、内部体验权益 | 不隐式扩展跨店合单、分账或真实渠道 |
| 数据结构回退 | V1–V15 迁移不可变，V13扩展权益来源 | 旧版本回退须验证 schema/事件兼容；业务副作用走补偿 |
| 前端体积与部分列表上限 | 构建有大包提示；部分资产列表展示首批50条 | 实际数据量增长后按模块拆包和补齐游标交互 |

本地验收没有发现未处理的 P0 证据；这不是完整安全审计或生产无风险声明。未制定真实峰值吞吐、延迟分位数、RTO/RPO或保留期限，不编造达标数字。
