# 前端视觉改版需求

用户要求修改当前 commerce-platform 前端，以真实页面验证已更新的前端架构 Skill。已确认偏好是简洁精致的企业工作台与重视图片的展示页面；没有已认可的具体样稿、颜色或字体。本轮授权包含设计与实现、既有本地环境验证、必要文档及按用户 AGENTS 规则正常 Git 交付，不含生产部署。

Brownfield：React 19、TypeScript、Ant Design 6、Vite；Hash 路由、Bearer 会话、真实 API 与 MySQL 数据源沿用。范围为登录、共享管理台/会员壳层、经营总览、共享列表/详情/表单以及现有会员商城/商品详情/购物袋。按角色和既有路由组织，不新增官网、身份系统、营销能力或业务 API。

设计意图：保留现有蓝色识别的色系，调整中性色、状态重量、密度与比例；工作台采用安静导航、清晰上下文、舒适排版与低重量状态；商城采用图片主导的商品卡、可读价格与触达按钮。具体颜色/尺寸由本轮设计 Owner 提出，仍是可调整假设，不写成用户认可。

代表页面先选经营总览，实际浏览器查看后复用到列表、表单及会员商城。桌面覆盖 1440/1280 宽，既有窄屏 390 宽；保持商品图片来源、目录金额、报价/下单、403/409/网络未知及版本规则。种子仅写新隔离租户，使用既有脚本的私密输出副本，不覆盖用户已有凭据文件。

验收：同数据/视口的改前与改后截图；当前版本真实取图并查看；全页不横向溢出，宽表在自身容器滚动；字段错误、弹层、图片加载/缺图、键盘导航和焦点可辨；经营数值、商品、订单与付款流程保持真实接口；构建与适用浏览器回归通过。美观方向由模型按用户偏好执行，但本轮自审不等于用户认可。
