# 页面与关联交互覆盖

范围依据当前 App 路由、23 份业务 feature 与共享原语。状态/数据继续以各已发布契约及类型客户端为准；下面是前端改善与验收归属，完成结果最终绑定 TEST_RESULT/capture 清单。

| 页面族/入口 | 关联交互与选用方式 | 关注点 | 责任片 |
|---|---|---|---|
| 登录、管理壳层、经营总览 | 既有凭据表单、导航/搜索、数据展开；复用现有主题 | 焦点、原有导航与加载/错误不回归 | UX-02 |
| 活动、动态规则 | 业务配置抽屉、真实优惠预览、活动侧编辑、规则短 modal、治理动作 | 同组轻量操作、资格/优惠/时效、条件树、提交/关闭/返回 | UX-01 |
| 会员档案、标签、成长 | 档案侧详情/操作菜单、成长/标签/积分/周期/行为子页、短命令表单 | 真实档案/流水、分组、原因/错误、菜单焦点 | UX-02 |
| 动态人群、人群快照 | 人群条件/成员/运行详情、版本编辑与快照命令 | 条件/成员/运行分组，陈旧资格按契约展示 | UX-02 |
| 商品经营（ADMIN/OPERATOR） | SKU/SPU 表单、图片/条码/渠道、修订记录、排程/批量作业 | 行操作、媒体/长字段、固定表单动作与现有权限边界 | UX-02 |
| 库存、商家、店铺、经营授权 | 共享业务详情与短 modal | 数量/身份/关联/版本清楚，授权危险操作及原因 | UX-02 |
| 预算、优惠券、定向发券、权益定义/台账 | 额度/有效期详情、发券/补偿表单与发放记录 | 金额/数量语义、用途/结果、真实发放/补偿状态 | UX-02 |
| 营销效果、生命周期效果 | 真实查询、分析/归因详情与现有分组页 | 不编造指标，日期/口径、错误/无结果 | UX-02 |
| 营销旅程、扫描、实例 | 节点/版本详情、侧编辑、扫描记录与实例处理 | 节点业务语义，长表单/明细滚动，取消/失败恢复 | UX-02 |
| 运营页面 | 页面编排侧工作区、真实页面预览、发布/回退 | 编排/预览区分，长表单动作可达、版本与回退规则 | UX-02 |
| 订单（ADMIN/MEMBER） | 快速抽屉与完整路由工作区、支付状态、售后短申请 | 身份/金额/商品明细、加载/无权、深链/返回、实际命令结果 | UX-03 |
| 履约、售后、退款、异步事件 | 业务详情与合法处理动作，必要短命令表单 | 状态/物流/原订单/失败原因，异步未知不假成功 | UX-02 |
| 会员商城、商品详情、购物袋/结算 | 既有图文目录、商品 modal 和购物/结算 drawer | 图片、触控、软键盘/窄屏、真实报价/错误、关闭恢复 | UX-03 |
| 会员订单、券、权益、成长、售后、消息 | 会员专属列表/详情及真实领取/兑换/核销命令 | 权限、金额/时效、角色密度、返回/反馈与原流程 | UX-02/03 |

共享变更直接影响 `RowActions`、`Detail/RecordFields`、`CommandModal/Fields`、`Pager/ListPanel` 与采用共同 Drawer 的消费者。每个入口都检查正常或真实空态；不同布局的代表详情/编辑/预览分别打开并截图查看。现有 E2E 覆盖非法状态与真实隔离数据的写流程；新增行为验证专注未保存保护、关闭/焦点、分页边界和完整订单返回，不复制实现做空洞测试。

桌面 1440/1280、既有 390 窄屏；管理宽表内部滚动，会员触控原要求继续适用。没有真实数据或权限的界面如实记录缺口/等价 fixture 边界，不将未打开的详情或未执行行为写 PASS。
