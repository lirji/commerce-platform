# 商品经营页独立视觉审阅

独立审阅者先收到 X、Y 两个匿名图集，实际查看两组的 `1440x900-normal.png`、`1440x900-detail.png`、`1440x900-empty.png`、`1440x900-service-error.png`、`1920x1080-normal.png`、`390x844-normal.png`。确认观点后揭盲，X 对应 A，Y 对应 B。审阅以完成「查找 SKU、核对名称状态售价、查看条码、返回原筛选」为目标。

- 两种桌面宽度，X 的查询动作和重置清楚，价格邻接条码，1920 可一行读更长 SKU。Y 的「规格列表」标题和条码操作更明确，1920 首列过宽且优先强调创建。
- 390 的 Y 表头约提前 20px，低频条件收进「更多条件」。两组首屏均见名称、售价和状态，条码操作需横滚。
- 两组错误与无结果区分清楚，有重试路径，X 有整组重置。
- 原 X 1440 详情照片只有遮罩。稳定条件下重拍后，审阅者查看 A、B 两组各 1440×900 与 1920×1080 共四张图，均见内容、当前条码、维护入口和返回按钮。原图作为采集失误反例保存。
- X 在高频桌面查询更均衡，Y 在窄屏和条码入口有实质收益。视觉结果没有一致的跨视口优胜。筛选、返回与价格真实性由 Playwright 行为证据覆盖，代表岗位效率未取样。
