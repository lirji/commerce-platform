# 优化需求清单

P0 指可能资损、严重误操作、数据错误或核心不可用。P1 指高频阻碍，P2 指常规可用性，P3 指低频增强。T1 是现有前端交互与字段调整，T2 是接口/只读投影，T3 是数据结构、规则或跨团队，T4 是系统级能力。条目以本次审计发现或候选为依据。尚无证据将具体业务资损列为已发生 P0，风险中的 P0 候选按相关复核项处理。
