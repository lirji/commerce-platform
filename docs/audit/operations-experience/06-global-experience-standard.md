# 全局运营体验规范

现有基线为 Ant Design、`theme.ts`、共享页面头、状态、筛选、游标、交互容器与两种壳层。后续沿用现有 React/Vite、同源发布和页面加载方式，借现有组件统一行为。变更顺序先核对业务判断和数据权限，再调整布局。

## 入口与页面模板

| 场景 | 交互标准 | 复用及验收 |
| --- | --- | --- |
| 多工作空间入口 | 经营总览负责看与办，商品与库存负责管理规格/安全变更，订单和售后负责客户问题，平台运行的技术入口保留。菜单和标题用作业词汇，“授权商品目录”“商品规格与计划”区分用途，协作命名说明是外部门店业务。暂以现有岗位可见菜单为顺序基线。 | 全局搜索继续读实际可达页面，以本人导航与编译入口的交集显示中央菜单。换组织时隔离旧缓存、旧筛选、草稿与待执行选择。 [导航](../../../frontend/src/iam/businessNavigation.ts)。 |
| 经营总览 | 头部先给当前店/租户范围、时间窗和来源。趋势按已付、实收、退款、净收解释，真实异常和待办可到同范围明细。 | 复用现有趋势和聚合。无源读权、同期无对象、在途或投影过期各有展示。 |
| 队列与列表 | 标题 + 实际范围 + 常用筛选 + 列表主任务。名称带标识复制，状态和金额/数量置前。宽表固定首列与行任务，长值可展开或复制。 | 复用 `ListPanel`、`RecordHero`、`RowActions`。避免页首多套工具栏和无作用域提示。场景间同语义才共用字段。 |
| 详情 | 顶部放业务对象、状态、范围、主要数量，继续给关键事实、关联、历史和动作。短且单任务用居中弹层。需要分享、持续处理、历史和多业务事实时用完整工作区。 | 复用订单快捷/完整详情和有状态的审计容器。返回恢复适用筛选、游标、滚动和焦点。多列表关系按真实所有权读取。 |
| 配置/审批 | 按基本信息、适用范围、规则/资源、确认结果分块。高风险信息靠近确认。新增和编辑展示必填、单位、例子、原值与新值，离开恢复保留已输入项且不替用户提交。 | 复用当前 Ant Form 与校验。跨版本复制创建新草稿、核新权限，金额、资产、预算快照采用后端验证。 |
| 会员浏览 | 主视图突出商品、订单状态及下一步，页面卡片的店、价、数量和有效期从真实数据读取。购物袋与报价区显式区分目录展示价和最终锁定应付。 | 同主题权威，保持会员端独立阅读密度。使用实际商品图和替代文本，空图与加载态可认。 |

## 表格、筛选、状态和数据

- **默认列**　同行检查对象、当前状态、金额/数量和业务时间，低频 ID、控制锁版本、技术追踪移到详情或可选列。保留核心列上的键盘可访问复制。没有真实总量时显示本批条数，不推算总页。
- **查询控件**　桌面显示一个命名与作用对象一致的主过滤区。高频关键词和状态常驻，时间、技术标识与每页放入高级/页尾，真实枚举可作快捷预设。筛选摘要与服务端实际请求一致，提交或重置回首批。标明生效范围和查询生效时间。只在明确许可时携带敏感标识，凭据、草稿和原幂等命令不进 URL。
- **金额及数量**　CNY 元保留两位小数和千分位，按契约精确取值，对账写清原价、优惠、应付、实收、退款与净收。数量标件、份、单位、积分及时间精度，百分比与基点分开说明。占用、可用、在途、消耗及剩余采用业务权威语义。
- **时间**　展示业务时区或 UTC，并区分创建、有效窗、渠道事实时间、投影更新时间。可比较的区间使用服务端约定的起止边界，解释终点是否包含。无原时间显示缺失状态，避免把取数时间当刷新时点。
- **状态**　映射已有稳定 code，不用中文文案做业务分支。共享颜色和形态，按域命名。SKU 可用状态用“已上架”，会员可用用“正常”，支付中、原退款待核对、已发券与批次已受理保留各自状态。
- **空、零和失败**　零表示有效的 0。空条件无匹配给调整/重置，一点数据都没有给首个合法动作，读取失败保留上次数据时标明过时，提供可执行重试。权限缺失提示请求/联系入口，按业务治理规则避免披露其他范围的对象是否存在。

## 命令反馈与恢复

| 情境 | 标准表现 | 验收 |
| --- | --- | --- |
| 普通可逆动作 | 发起后按钮忙态，对成功内容给准确反馈，读取原结果刷新关联信息。 | 只有接口成功且权威状态明确才用“已完成”。 |
| 受理或运行中 | 标“已受理/处理中”，给任务编号、下一步或合法回执入口。 | 有逐项结果就展示成功/跳过/保留/未处理，估算与实绩口径明确。 |
| 未知结果/超时 | 有幂等键时保留同一目标与请求，提供原样确认或实际查询，无键时说明先核对实际状态。 | 在隔离环境模拟响应丢失，服务端只一笔，用户可在当前用途恢复，不重复执行副作用。 |
| 409、撤权或服务不可用 | 409 说明版本变化，刷新原事实再允许合法提交。401 按链清会话，403 或来源不可用只隐藏相应事实。 | 调换可见角色及组织，旧页数据、草稿、列表和操作候选全部按新资格。503/网络异常区分空结果。 |
| 高影响设置或审批 | 展示原对象、准确范围、实际版本、前后对照、执行窗口及已有止损。操作确认与具体副作用对应。 | 不给低风险搜索或普通详情多余确认。批量预检结果绑定计划，改范围立即失效。 |

## 视觉和可访问性验收

保持现有浅色工作台、深色导航和同一主题 token，主可执行按钮由 Ant Design 主色与对应焦点样式体现。当前订单、规格、售后是验证样本，分别覆盖宽表、多工具栏与任务弹层。使用 1440、1024、390、320px 和键盘流程逐步验收。窄屏优先看到对象和当前任务，额外字段用受控容器滚动，文档无横向溢出，固定列不会遮住行操作。弹层打开时焦点可预测，标题具名，Esc 对允许关闭的状态有效，返回恢复相应焦点。状态同时用文本表达，实际对比度、缩放、读屏路线纳入后续验证。当前已查看商品双工具栏、窄屏订单和中央关闭状态截屏，其它布局依据页面观察和源码，方案为本次建议。
