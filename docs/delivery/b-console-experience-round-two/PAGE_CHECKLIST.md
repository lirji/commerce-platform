# 第二轮 B 端页面验收清单

本轮使用[首轮逐路由清单](../b-console-product-experience/PAGE_CHECKLIST.md)作为页面索引。旧运营菜单与中央真实菜单契约仍提供路由来源。门店商品在门店角色单独验证，即使路径和旧运营入口相同。

| 范围 | 本轮变化 | 浏览器验收 |
| --- | --- | --- |
| 经营总览（旧运营、中央） | 同店连续完整七日对比、7/14/30 日图表、键盘日期选择、可排序每日明细、待办数量视觉层级 | 实际接口检查桌面与移动端。对照用例核验负数、零、部分日排除和 URL 恢复 |
| 交易与交付（订单、履约、支付、售后、退款） | 共享游标双向访问和筛选态、操作列、表格展示偏好。待办按门店和原队列条件下钻 | 验证查找、审批与退款详情、原单入口、状态筛选、详情重试和返回 |
| 商品、库存、商家、门店与授权 | 授权商品数和覆盖门店数、零可售提示、库存预占占比、统一门店状态、业务编号复制、表格密度与列设置 | 核验旧运营和中央布局、授权门店、库存窄屏、商品批选、列设置、编号复制及导出任务 |
| 营销活动、预算、效果、券定义、发券、权益、规则 | 活动截止提示、既有预算占用、发券已处理中的发放比例、权益待补偿、表格筛选和操作区 | 核验版本数据、预算独立入口、发券回执、提交中禁重复及撤权 |
| 旅程、实例、扫描、运营页面、事件、工作恢复、重放 | 公共布局与列表改进。生命周期扫描可调页容量，保留实际游标 | 核验已访问页、重新查询、关系图、异步事件和操作帮助、权限提示 |
| 会员档案、成长、标签、人群、快照、积分、周期、行为、兑换 | 共享密度、列设置、滚动、查询与分页状态、反馈和核心编号 | 按逐路由索引渲染，核验独立权限读取、固定版本和撤权 |
| 平台运行健康、分类字典、操作日志 | 保留健康采样。类目按一级分组分页并说明节点数。日志可跳到已访问页并记忆容量 | 核验平台角色、分类筛选与排序、日志过滤、详情和真实历史 |

## 浏览器范围

- 旧运营 29 个入口使用当前本机接口只读检查。核心页面包含 320、390、1024、1440 和 1920 px。
- 门店与平台 4 个角色场景，以及中央 36 个契约入口，用独立浏览器会话按实际角色和返回体形状检查。
- 老登录、未知路由、组织入口、撤权、详情深链接及会员页面兼容仍随项目回归执行。
- 配置页以表单和操作效率为主。统计范围以及等待支持的任意页跳转见[数据要求](DATA_REQUIREMENTS.md)。
