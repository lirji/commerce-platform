# 数据口径与接口缺口

## 本轮已使用的数据

| 展示 | 数据来源和口径 |
| --- | --- |
| 同店七日环比 | `/v1/admin/dashboard` 的日投影，按 UTC 下单日取最近两个连续的完整七日，排除当日部分时段。基期为零或负时展示金额差额。退款覆盖截至已知投影的成功退款 |
| 匹配商品、覆盖门店 | 中央授权商品查询的 `total` 和 `stores`，按该查询范围展示。确切总页数由总记录数和每页容量计算 |
| 库存、活动和权益 | `held`、`available`、已发布活动的有效结束时间，以及实际 `compensationDebt`。72 小时为本轮界面提醒阈值，服务端状态由原规则决定 |
| 发券进度 | 当前批次 `issued / processed`，表示已处理记录中成功发放的比例。目标人群完成率需要独立分母 |
| 售后与订单异常 | 沿用同一门店、同一原条件的有界异常队列。达到读取上限时显示下界 |
| 平台分类 | 目录接口返回完整分类树。总页数以一级节点为单位，节点数包含匹配的下级及其保留的父级路径 |

## 待补充的接口能力

| 页面 | 需要的数据 |
| --- | --- |
| 主要游标列表 | 在已有授权和查询范围内返回 `totalCount`、`hasMore`，并提供任意页定位、可核对快照及过期恢复。当前未访问位置仍由服务端下一游标导航 |
| 订单、售后、商品、门店、营销及权益 | 与列表同范围、同权限、同时间条件的 `statusCounts` 及聚合 `asOf`，异常队列增加最久等待时间和 SLA 条件 |
| 总览和门店 | 历史同期聚合、门店组聚合、实际投影覆盖和完整窗口标记。可支持同比、特定经营日时区和跨门店比较 |
| 库存和营销活动 | 门店与 SKU 的可售阈值及依据，活动固定版本对应的预算和实际截止策略 |
| 券与权益 | 批次冻结目标数、去重后的处理和失败分类、完成时点及补偿待办计数 |

字段、权限与验收细节沿用[首轮接口需求](../b-console-product-experience/DATA_REQUIREMENTS.md)。
