# 交易中心 B 端产品体验升级

基线 `ed1b7ac`，任务分支 `feat/b-console-product-experience`。本次需求明确授权在原有视觉和业务契约内直接实施。用项目现有 localhost 只读业务环境和浏览器测试夹具验收。按工作区规则正常提交和发布 main。用户后续授权将通过验证的版本部署到本机 Docker 8602。

| 验收 | 实现范围 | 证据 |
| --- | --- | --- |
| AC-01 全路由 | 旧运营、门店经营、平台和中央授权工作台；追踪兼容入口、组织落地和登录边界 | 路由检查清单、实际入口桌面与移动检查 |
| AC-02 列表作业 | Ant Table 共用工具、可访问的列设置、行密度、全屏、关键编号复制。保留原筛选、操作、排序和范围判断 | 样例操作、窄屏、原请求和表格回归 |
| AC-03 准确分页 | 完整数据集展示总数、页码、页容量和跳页。已知总量的游标显示总页数及可用游标，普通游标提供已访问页 | 本地数据分页与游标前进、返回、刷新、变更范围、重置验证 |
| AC-04 筛选与表单 | Ant 日期时间控件、时间快捷条件、已生效筛选、紧凑排版及提交反馈 | 核对键盘、表单草稿、原请求格式与日期边界 |
| AC-05 业务洞察 | 复用真实经营总览、异常队列、活动成本、单批发券结果、单库存行与已授权目录统计；只为有决策价值的数据增加读图入口 | 现有响应与显示比对，区分零值、空值和错误 |
| AC-06 交付 | 弹层/写操作回归、桌面和窄屏、类型、构建、变更文件格式检查、团队 CI 与 Git 回执 | Playwright、本地运行、校验日志、CI |

沿用 React、Ant Design、现有主题及 API 客户端。依次交付共享控件和表格、经营模块内的差异化处理、逐页验收与 Git 交付。保留正在使用的详情与命令处理链，按原接口决定哪些筛选和数据可联动。沿用项目现有 GitHub Actions；以正常 revert 提供代码回退。跨期和各模块汇总、未访问页跳转依赖等数据缺口在随附清单记录。

采用 `~/.codex/architecture-standards.md` 的业务建模与代码组织、分布式协作与接口契约、并发安全与验证、发布与数据治理章节，以及个人技术栈的 React 管理后台和前端个人偏好。
