# 交易中心 B 端体验升级交付报告

## 页面与体验

- 经营壳层继续使用现有主题和导航。收紧标题、筛选、工具条及手机指标区。支持宽屏列表布局。入口范围见 [页面检查清单](PAGE_CHECKLIST.md)。
- 共用 Ant Table 工具提供列显隐、行距、本页全屏、常用编号复制和横向位置恢复。桌面长表在表内固定表头，交易列表按幅面固定操作列。记录详情及业务提交继续使用各页原路径，详情弹层保留焦点恢复及错误处理。
- 交易、店铺、活动、发券和权益页提供状态快筛，使用原服务端状态参数。日期时间控件沿用本机时间输入，再按既有接口序列化。支持今天、昨天、近 7 天、近 30 天和本月快捷条件。
- 协作商品显示服务端真实总数和总页数，规格及操作日志加入页容量选择。已访问游标页可跳转。总览每日明细直接分页服务端返回的完整日序列。
- 总览金额指标切换同一份成交趋势，会员和 SKU 状态分布来自各自统计范围。预算占用基于原版本额度、已支出和预占。发券结果使用该批次实际已处理的发放和跳过构成。库存零可售和全额占用预算提供行级提示。营销效果的已付比例采用同一活动行的订单数。
- 交易、审计和配置原有操作路径继续使用现有客户端、权限和命令回执。批量商品和恢复任务切页时清理旧选中记录。读请求换条件时同步移除旧结果，保留错误与重试入口。

## 读取契约

列表统计和可视化采用现有业务响应。没有完整统计、跳页定位或告警阈值的模块见 [数据接口与字段需求](DATA_REQUIREMENTS.md)。中央协作的已访页仍受服务端游标有效期约束。

复用 Ant Design 日期选择器和其已经锁定的 Day.js 版本。业务接口、数据库、权限规则及运行配置无变更。发布、验证证据和恢复入口见 [交付状态](DELIVERY_STATUS.md)。
