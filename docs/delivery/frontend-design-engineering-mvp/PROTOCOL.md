# 商品经营页 A/B 实验协议

冻结于实验执行前。两组各从 107a8c0a81e07073ced12dc6a3282c2908de1e4a 的专用工作树出发，共用原始业务请求 REQUEST.md、锁文件、隔离 Java API/MySQL fixture、浏览器、视口、状态、允许写集、两轮执行、工具权限、模型 gpt-6.2-sol 及 medium 推理设置。每轮用干净 Codex CLI 会话。CLI --ignore-user-config、workspace-write、approval_policy=never、network_access=false，不提交、不装工具。控制器将在相同状态与顺序获取截图；每组下一轮接受自己的截图与同等问题复核机会，组间源码、图片或分析不共享。原版单独作参考，不是 A 组。

唯一计划内处理差异是 A 使用已生效 frontend-design 指引，B 使用该指引及隔离候选的页面设计方法与结构化验收约束。试验执行通过有界本地 CLI，会单独运行候选 Compiler/Planner/Quality 回归验证；本身不构成生产 Driver 认证。CLI 字段用于实测时间与 Token，分别记 input、cached input、output 与 reasoning。一次任务和一次模型运行不足以给出统计显著性。

对照指标固定为视觉结构、商业表达、信息识别（目标名称/状态/售价是否可辨、首次筛选位置、主次）、真实筛选和详情返回完成、交互状态、复用与视觉一致性、墙钟和 Token。每轮都以相同窗口截取正常、详情及无结果，窄屏按相同附加场景。行为用同一自动脚本和不变的断言。主观视觉审阅按匿名截图组和同一任务，顺序固定为实验随机映射，评价证据保留图片与具体观察。没有代表岗位用时即仅报告操作步骤、可见性和自动化耗时。建议正式纳入需看到 B 相对 A 明确改善并满足其余关键条件。
