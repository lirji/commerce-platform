## 变更影响与架构一致性

候选过滤属于活动持久化与报价路径；第二权益涉及活动不可变配置、订单支付事务、券额度、营销执行及事件兼容；冲突规则属于纯决策器。旧 V41 数据必须保持原含义，数据库只允许新迁移扩展。旧节点不可识别的新业务配置须通过发布顺序及功能门禁约束，而不是寄希望于事件调度。无前端信息架构变更；如 API 展示新增权益类型，复用原执行查询。
