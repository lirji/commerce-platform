# 第三轮 B 端页面检查清单

逐路由的名称、角色和页面主任务沿用[现行 69 个入口索引](../b-console-product-experience/PAGE_CHECKLIST.md)。以下按角色记录本轮覆盖的页面族、切换入口和真实数据范围。历史设计中的会员自助入口另由工程回归覆盖。

| 入口 | 页面与主要操作 | 本轮验收方式 |
| --- | --- | --- |
| 旧运营 · 总览 | 门店待办下钻，四项指标，UTC 日柱状图、时间切换、对比和日明细 | 真实接口五种宽度。受控正、负、零值验证图形、焦点、日期与刷新 |
| 旧运营 · 会员 5 页 | 会员、成长、标签、动态人群及人群快照。保留查找、版本与详情 | 真实接口逐入口；夹具验证查询、空态、错误和详细弹层 |
| 旧运营 · 商品与门店 5 页 | 商品规格、商品资料、计划和目录子页签；库存、商家、店铺及经营授权 | 真实接口逐入口；表格设置、键盘横滚、门店身份、开店和批选回归 |
| 旧运营 · 营销 10 页 | 活动、效果、规则、预算、券、发券、权益定义、权益台账、旅程和实例 | 真实接口逐入口；条件、游标、版本、预算、试算、发券回执及关系图回归 |
| 旧运营 · 交易 4 页 | 订单列表、快速查看、完整详情及原单返回；履约、售后、退款 | 真实接口五种或两种宽度；只读下钻和回退，隔离用例覆盖原交易流程 |
| 旧运营 · 工具 4 页 | 低代码页面、异步事件、任务恢复和历史重放。包括新建与派生新版本 | 真实接口逐入口；表单初值、输入、预览、关闭和原任务状态回归 |
| 门店经营 · 商品 1 页 | 同一组件按门店经营角色显示商品作业 | 门店角色契约，320、390、1024、1440 px |
| 平台 · 工具 3 页 | 运行健康、平台分类、操作日志 | 平台角色契约，320、390、1024、1440 px。独立分页和审计用例按隔离环境运行 |
| 中央 · 36 个授权或协作页 | 按声明菜单逐入口核对。交易、店铺、库存、商品协作、营销、会员、动态规则、任务和配置均进入各自工作区 | 中央导航及业务响应契约矩阵，320、390、1440 px。岗位和业务操作由专用用例核对 |

跨页操作核对宽表普通与全屏的键盘定位和返回、查询与重置、已访问页跳转及已知总页数、焦点、业务编号复制、首次加载、失败重试和权限拒绝。订单详情保持可深链，返回恢复已应用筛选、原游标和列表位置。登录、会话退出、组织入口和回调属于导航边界。菜单声明中的 `/products` 和 `/stores` 是历史兼容资源，当前工作区使用 36 个编译入口。真实中央 PKCE 取决于可用的隔离岗位帐号及身份提供方。

浏览器结果与数据范围见[交付状态](DELIVERY_STATUS.md)。缺失接口见[数据需求](DATA_REQUIREMENTS.md)。
