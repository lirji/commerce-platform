# OP01–OP08 consolidated review

范围：基线 fb7adf6 至本任务变更，检查源码、XML、V16–V22、API、安全入口和运营页面。不是原平台全仓审查；旧外部适配和生产容量风险仍保留。

## 已核对的业务与失败路径

- 权限：ADMIN/OPERATOR/MEMBER 分开；经营接口逐次查有效资源授权，旧 admin 接口不放宽；店铺查询 SQL 过滤并限制游标。撤销及跨店/跨租户测试覆盖。
- 生命周期/价格：会员终态和商品状态显式约束；CAS 更新与历史入库同事务。历史订单沿原报价，促销商品范围分摊不会转嫁给未参与商品。
- 成长：会员锁串行，权威完成/成功退款净贡献按原策略重算，来源唯一键与版本条件保护重投/乱序；负成长保留冲回债务。
- 人群：一租户一批最多100会员、最多64标签；完整快照头才公开，取消/超额/过期不发布；扫描游标和入组事件 Outbox 检查点持久化，隔离后有重试入口。
- 旅程：新会员触发只消费发布后事实；当前会员状态复核，跨版本频控行锁与唯一效果记录；节点执行与效果同事务。新增真实并发入组测试验证单次上限，冲突返回409可重试，不承诺所有并发请求都成功。
- 分析：只通过公开领域 API 取权威订单/报价/成功退款合计；tenant+order唯一投影，旧观察不能回退累计成交/退款。历史重建100单分页，不开长事务、不写交易表。
- 没有新增依赖或公共中间件；Maven 架构测试阻止跨领域访问非 api 包。未提交秘密，演示凭据只保存在忽略文件，截图不含凭据输入。
