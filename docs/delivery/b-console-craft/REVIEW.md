# 品质自查与修订

依据 [Webby 官方标准](https://www.webbyawards.com/judging-criteria/)核对导航、视觉、功能、交互、内容与整体体验；Awwwards/FWA本轮未获取可核对的官方评判文本，不编造权重或品质得分。

| 实际发现 | 修订 | 复查 |
|---|---|---|
| KPI权重平均、负净收被裁零 | 主净收/辅助事实层级，正负同轴零基线，准确保留decimal显示 | 正/负/零及全负数据三浏览器；真实总览截图 |
| SKU动作滚动外、历史详情先看原始数据 | 固定桌面动作，选中对象和版本前置，窄屏内部滚动 | 真实商品历史、390截图与业务回归 |
| 中央重复组织与目录页头 | 共用组织上下文；目录embedded仅抑制内页头，保留业务逻辑 | 17入口截图逐族查看，最终目录图仅一个标题 |
| 登录首包包含中央能力 | 中央根和业务模块按需lazy | 实际dist网络相较基线减少约17.6%解码字节；未下载中央模块 |
| 必填星号污染字段名称，快捷键移走弹窗焦点 | CSS星号+aria-hidden空span，aria-required保留；可见dialog时不聚焦背景搜索 | 原有精确字段查找及三浏览器焦点测试保持 |
| 旅程平铺详情无法看分支 | 正式版本关系图，文字分支与当前节点真实事实 | 复杂分支边界与真实持久化两节点旅程，未造执行状态 |
| 新图SVG后代规则影响节点图标 | 仅直接子SVG定位 | 实际渲染查看后修复，并重新截图 |
| 720默认详情落到首屏下方 | 1120默认图/详情并排，可收起720，390内滚动 | 节点详情在视口、收起/展开及手机实测 |
| WebKit打开按钮不自动持有焦点 | 打开前显式focus，关闭恢复原按钮 | WebKit失败保留，修正后全部22项通过 |

当前评审没有未解决的功能/布局阻塞。视觉层级、真实数据探索、业务关系图与细节一致性较基线明确改进；不存在可诚实证明“必定获得三大奖”的自动门槛，故不宣称已获奖或编造分数。真实外部评审/用户研究、完整无障碍审计、生产性能不在已验证事实中。没有新框架、动画依赖或生产部署。
