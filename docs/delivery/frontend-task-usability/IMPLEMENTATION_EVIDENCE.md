# 前端任务与恢复优化：实施和验证

用户要求按Claude最新前端技能优化已有项目。实际使用当前个人`frontend-design`及其共享交互、视觉、工作台和验证规则；入口、版本指纹与范围见[计划](PLAN.md)。本记录由同一实施者Codex整理，不作为独立Validation或Claude原生客户端执行记录。

## 结果

筛选草稿现在明确显示“点击查询后生效”，已应用条件可分别清除，默认条件下重置也能清掉未提交输入。清除条件保留其他已应用条件并从首段查询，刷新仍恢复URL中的查询。关键词说明沿用接口支持的真实字段。低代码运营目录接入已有后端关键词、状态和limit参数，不增加接口或页面假数据。

47个文件的125处读取错误显示就地“重试加载”，保留筛选和输入；401/403不提供重试。调用只绑定既有`useResource.refresh`，命令的幂等键、未知结果和恢复处理仍由原业务路径负责。共享HTTP状态常量保留`iam/api`原导出名，避免改变现有调用约定。

运营、会员和中央壳层提供键盘“跳到业务内容”，焦点进入main且不改变URL。真实溢出的ListPanel可聚焦并用左右键滚动内部表格；短表不增加Tab停靠点，行操作和输入控件不被截获。从“更多”菜单打开档案后，关闭返回仍存在的原行按钮；不把焦点留在已卸载菜单项，也不移出仍打开的嵌套弹层。

保持32px常用按钮和居中弹层。真实数据库数据检查发现动态人群按钮组、营销日期表单、低代码宽表和会员成长卡片在320px下撑宽页面，已分别修复换行、表内滚动和grid最小列宽。错误追踪号可换行，手机错误说明保持整行，重试按钮另起一行。
